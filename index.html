Einstellungen

Einen kostenlosen Schlüssel gibt es auf dev.pokemontcg.io.

KI-Erkennung (optional)

Mit Schlüssel liest Claude (KI) jede Karte – auch mit Spiegelung, schief oder auf Chinesisch. Dafür wird das Kartenbild an Anthropic geschickt. Kosten: ca. 0,01 Cent pro Karte, abgerechnet über dein Guthaben auf console.anthropic.com. Ohne Schlüssel bleibt alles kostenlos auf dem Handy.

Sicherung

Die Sammlungen liegen nur auf diesem Gerät. Eine Sicherung schützt vor Verlust, z. B. beim Handywechsel.
